This folder contains the results from performing GRN inference with pyScenic on the Cadot et al, 2020 dataset. 

The network, network pruning and TF scoring is performed in the pyScenic_full_pipeline.ipynb notebook. 
To run the notebook, you must have pyScenic installed. Visit https://pyscenic.readthedocs.io/en/latest/ to find the instalation guidelines. 

In addition, to complete the analysis, you must download the cisTarget feather and motif annotation files. Please visit https://resources.aertslab.org/cistarget/databases/homo_sapiens/ for downloading the cisTarget feather files and https://resources.aertslab.org/cistarget/motif2tf/ for downloading the motif annotation files.
